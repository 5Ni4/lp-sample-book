# サロンサイト移行｜素材の保全チェック

この試作ブランチはGitHub Pagesの公開対象外ですが、リポジトリ自体は公開です。実在の店名、施術写真、お客様の声、書き出し原本、管理情報はここに置きません。

| 素材 | 取るもの | 確認 |
| --- | --- | --- |
| サイトのページ | トップ、プロフィール、施術、料金、感想、予約・アクセス、その他のメニュー | ページURL・タイトル・掲載の要否を照合 |
| ブログ | 記事、カテゴリ、日付、原稿 | 保全する本数と新サイトに載せる本数を別に数える |
| 画像 | 写真原本、各記事の画像、ロゴ | 素材ごとに権利・同意・代替テキスト・表示を確認 |
| デザイン | 配色、書体、余白、トップ画像、スマホとPCの見え方 | 設定・テーマ・カスタムCSSはCMSの書き出しで引き継がない前提 |
| 外部連携 | 予約ボタン、SNS、埋め込みカレンダー、地図 | URL・管理者・移行後の挙動を個別確認 |
| 切り替え | ドメイン、旧URLの一覧、移転案内 | 旧サイトの管理権限と切替日時を確認 |

## 保全する順番
1. サイトの所有者か管理者に、管理画面から書き出しを依頼する。非公開記事や下書きを含む原本は、制作・公開用と分けて本人が許可した非公開保管先へ置く。
2. 画像のファイルそのものを別に取得する。書き出しにURLが含まれていても、画像の保存済みとは扱わない。
3. 新サイトへ載せる素材を選び、許可済みの範囲だけ制作環境に取り込む。下書き・予約投稿を勝手に公開しない。
4. URLごとの移行可否、データ件数と画像の表示、リンク切れを照合する。
