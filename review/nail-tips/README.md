# 指先日和の画像レビュー

左が公開中の旧版、右がドラフトの変更版です。ヒーロー、商品一覧、3商品の詳細、バッグ、注文デモを同じ画面幅で比較できます。

- [PCの比較画像（1440px）](compare-pc.webp)
- [スマホの比較画像（390px）](compare-mobile.webp)

## 画像の出どころ

4点とも、この架空ショップ用に OpenAI の画像生成機能で新規制作しました。第三者の写真、参照画像、ロゴは使っていません。淡いベージュの紙と左上からの窓光を共通にし、ローズの金の細線、ライラックの銀箔、乳白色の小粒パールを描写しています。ヒーローは3色を並べた別カットです。現物の撮影は行っておらず、商品ページにも生成画像である旨を記載しました。

4点を WebP 化し、画像合計を約210 KiBにしました。商品詳細とバッグは一覧と同じ画像を使います。バッグは商品名を隣に表示するため、サムネイルの代替テキストを空にしています。

## 確認結果

- 旧版は [公開ページ](https://5ni4.github.io/lp-sample-book/sites/nail-tips/) を Chromium で表示しました。変更版はローカルサーバーで同じページパスを開きました。
- Chromium の1440pxと390pxで、ヒーロー、一覧3点、詳細3点、バッグ3点を読み込み、比較画像を目視しました。画像の読み込みエラー、ページのJavaScriptエラー、横方向のはみ出しはありませんでした。
- サイズ案内へのリンク、5本分の入力からの M 推薦、全3商品をバッグに追加、数量変更と合計、注文確認、デモ完了を両方の幅で確認しました。
- 公開ワークフローと同じビルドスクリプトをローカルの空スナップショットで実行し、対象ページと画像のコピーを確認しました。検証対象は Chromium のビューポートで、実機とSafariは未確認です。
